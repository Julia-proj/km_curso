# HAIRLAB Project Rules

Это правила проекта HAIRLAB (курс восстановления волос, Мадрид).
Применяй их к КАЖДОМУ изменению кода и текста без исключений.

## 1. Тексты (русский копирайт)

- НИКОГДА не используй длинные тире (—). Только точки, запятые, двоеточия,
  обычный дефис. Это касается UI-текстов, AI-промтов, email, комментариев
  в content-файлах.
- Кавычки: «ёлочки» для русского текста.
- Запрещённые AI-обороты: «в современном мире», «не только... но и»,
  «ключевое значение», «погружаемся», «в эпоху», «является», «обладает»,
  «стоит отметить», «важно понимать». Живая речь, короткие предложения.
- Тон: поддерживающий, без запугивания и давления. Обращение на «ты».
- Запрещены медицинские термины в пользовательских текстах и AI-ответах:
  «лечение», «терапия», «диагноз», «алопеция». Вместо них: «уход»,
  «рекомендации», «анализ состояния».

## 2. Типографика и шрифты

- Display (заголовки): Fraunces, Google Fonts, ОБЯЗАТЕЛЬНО cyrillic subset.
- Body (текст и UI): Onest, Google Fonts, ОБЯЗАТЕЛЬНО cyrillic subset.
- ЗАПРЕЩЕНЫ: Inter, Geist, Roboto, Plus Jakarta Sans, Open Sans
  (AI-typical, удешевляют дизайн).
- Большие заголовки: clamp(42px, 7vw, 92px), letter-spacing -0.03em,
  line-height ~1.0.
- Один italic-акцент на заголовок (бронзовым цветом), как на обложках
  методичек.
- Микро-метки: uppercase, letter-spacing 0.18-0.22em, 11-12px.

## 3. Цвета и визуальный стиль

- Все цвета ТОЛЬКО через CSS-переменные в globals.css:
  --color-cream: #F4EFE6 (фон)
  --color-paper: #FBF8F2 (карточки)
  --color-ink: #1C1A17 (текст)
  --color-ink-soft: #57524B (вторичный текст)
  --color-bronze: #A98A5B (italic-акценты, как на обложках)
  --color-accent: #C9885B (CTA-кнопки)
  --color-line: rgba(28,26,23,0.14) (hairline-разделители)
- НИКОГДА не хардкодить hex в JSX/компонентах.
- border-radius максимум 2-4px. НИКАКИХ rounded-2xl.
- Разделители секций: 1px hairline. НЕ тени, НЕ цветные блоки.
- ЗАПРЕЩЕНЫ: градиенты, glow/shimmer/sparkle эффекты, blob-формы,
  эмодзи как декор (только ✓ и · допустимы), Lottie.
- Эстетика: editorial fashion-журнал (референс: обложки методичек HAIRLAB,
  oceanmuse.ru, archisite.ru). НЕ SaaS-стартап.

## 4. Код (solid-правила)

- Один компонент = один файл, максимум 200 строк. Больше — декомпозируй.
- ВСЕ тексты в /lib/content/*.ts типизированными объектами.
  В JSX никаких строковых литералов с копирайтом.
- ВСЕ URL, цены, даты, magic numbers в /lib/constants.ts.
- TypeScript strict. Никаких any без крайней необходимости и комментария.
- Server Components по умолчанию; 'use client' только где реально нужны
  хуки/события.
- Семантичный HTML: section, nav, h1-h3 по иерархии (один h1 на страницу),
  button для действий, a для переходов.
- Доступность: focus-кольца видимы, alt на всех картинках (русский),
  aria-label на кнопках-иконках.
- next/image для всех изображений с width/height.
- Секретные ключи (SERVICE_ROLE, STRIPE_SECRET) только в server-коде,
  никогда в client-компонентах и NEXT_PUBLIC_*.

## 5. Мобильная версия

- Фото в любой секции не выше 35vh на мобиле (Author-секция: до 40vh).
- В Hero на мобиле: текст и CTA в первых 60-65vh, фото ПОД текстом.
- Marquee только на десктопе (скрыт <768px).
- Sticky CTA-плашка внизу на мобиле: появляется после Hero, скрывается
  у футера, высота 56-64px.
- До/после и Reels на мобиле: горизонтальная карусель, не столбик.

## 6. Продажи (soft-sell)

- Принцип «у тебя есть выбор»: всегда минимум два пути (самостоятельный
  подбор по курсу / готовый pack в Мадриде), плюс третий выход
  «обсудить с Еленой».
- Запрещены: «купи срочно», «только сегодня» (кроме честного таймера
  с фиксированной датой), «обязательно нужно», давление и запугивание.
- Pack Limba подаётся как опция, не как главный CTA. Бейдж «только Мадрид».
- Подарки называются «в подарок», не «бонус».

## 7. Бизнес-логика (не ломать)

- Цены: методичка 12€, полный курс 38€ (со 138€). Каждый продукт это
  отдельная покупка со своей ссылкой Stripe. Менять только через constants.
- Таймер акции: фиксированная endDate в constants, НЕ сбрасывается при
  refresh. По истечении показывает «Акция завершена».
- AI rate-limit: 1 анализ на email навсегда (landing), 3 с одного IP
  за 24ч, 1 в 30 дней для кабинета. Disposable-домены блокируются.
- AI-ответы всегда с дисклеймером «это не медицинский диагноз».
- Фото пользователей: приватный bucket, signed URL максимум 10 минут.

## 8. После каждого изменения

- npm run build должен проходить без ошибок и warnings.
- Проверь изменённые страницы на 375px (текст не вылезает, фото ≤35vh).
- Если менял тексты: проверь на длинные тире и AI-обороты из раздела 1.
